saturn
------
- saturn does not play midi and the game originally came with midi
  - i read that saturn can deal with seq/ton which you can convert to from midi but i dont know how ponesound deals with that
  - i am instead converting from midi to wav and will play with cd audio
  - had to use audacity to add 2.5 sec of silence so beginning of song is heard properly
- i ran into some palette issues loading some of these graphics and had to do the following
  - load graphic in mtpaint
  - load palette in mtpaint
  - change the graphic to rgb mode
  - save the graphic as tga
- if your filename is longer than 8 chars, a font will appear with each character being only one pixel
- when loading a font, the spacing parameter is for how much spacing is displayed between characters on output
- there is a but with jo_font_print_centered that we need to work around to get good output quality
  - need to set scaling to 0.99f instead of default 1.0f
  - jo_font_print_centered(game_font, 0, 0, 0.99f, intro_text[current_intro_text_index]);
- if your sprite is showing up as garbage data, check that the dimensions are evenly divisible by 8

general
-------
- we have one make file per platform now, so to make we need to
  - cd into the platform specific build directory
  - run make clean (optional)
  - run make
- we will use a consistent naming convention: snake_case everything except MACRO and ENUMERATION_CONSTANTS	
- use magic wand in paint.net with global flood to select background colors and do fills
  - if we dont do this we have seen that the fill will influence nearby pixels by shading their value slightly
